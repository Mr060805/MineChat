# MineChat

**MineChat 是一款运行在 Android 上的 AI Agent 客户端，以 Agent 运行器（Agent Loop）为核心。**

模型运行在一个可持续运转的 Agent 里：拆解步骤、调用工具、读写工作区文件、挂载技能与知识库，把一件任务从头做完再回报结果。提示词管线可编辑，工具与技能按需装配——能力边界由配置决定，而不是由产品写死。

## 支持系统

- **最推荐 Android 13（API 33）及以上**：系统通知、权限与后台调度行为完整，体验最佳。
- 最低 **Android 8.0（API 26）**，更低版本无法安装。
- 包名 `com.mine.minechat`；本仓库仅分发安装包。

## 使用方法

### 主聊天页：输入区中间胶囊

输入框下方正中胶囊，这一控件上挂载**三种手势、三个入口**：

| 手势 | 做什么 |
| --- | --- |
| **点按**（单指轻点一下） | 打开**附件面板**，选图片或文件随消息一起发出 |
| **双击**（连点两下，间隔约 200 ms 内） | 回到**主页**（会话列表），带缩放转场 |
| **长按**（按住约半秒不放） | 浮出**手势选择器**：三枚圆以胶囊为圆心向上呈扇弧铺开 |

长按后**不松手**，手指直接滑向任意一枚圆，抬手即生效：

| 滑到哪 | 松手后 |
| --- | --- |
| 左 · **配置** | 打开当前会话的配置菜单：思考等级、运行模式、工具、记忆、注入、压缩 |
| 中 · **语音** | **手指一进这块就开始录音**；滑出去立即停止并识别，识别结果填回输入框。可以进进出出连说几段 |
| 右 · **加号** | 占位，暂未开放 |
| 空白处 / 胶囊上 | 取消，什么都不执行 |

> 记法：**点一下 = 加东西，点两下 = 回家，按住 = 挑工具**。

### 发送与停止

- 输入框有内容时，右下角按钮是**发送**；
- 正在生成时，同一个按钮按内容判断：**有内容 = 入队**（本轮结束后自动发出），**无内容 = 停止生成**；
- 左下角是模型 chip，点一下切换聊天模型与思考等级；
- 输入框最高撑到 5 行，再多就在框内滚动。
